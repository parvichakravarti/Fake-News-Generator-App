# 📰 Fake News Headline Generator

**A fun Streamlit app that generates hilarious, random, and totally fake news headlines!**  
Create your own headlines or let the app surprise you — all for fun and creativity 😄  

🔗 **Live App:** [https://fake-news-generator-app-9876.streamlit.app/](https://fake-news-generator-app-9876.streamlit.app/)

---

## 🚀 Features
- 🎭 Multiple headline styles – Funny, Serious (Satire), Crazy Mode  
- 🧠 Choose categories like Celebrities, Politics, Animals, and more  
- ✍️ Build your own custom headlines  
- 📜 View your headline history  
- 💻 Works perfectly on mobile and desktop  

---

## 💡 How to Run Locally
```bash
# Install dependencies
pip install streamlit

# Run the app
streamlit run fake_news_generator.py
